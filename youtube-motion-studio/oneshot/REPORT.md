# Everything is Connected — One-Shot (10s) 리포트

목표: 스크롤을 1초 안에 멈추게 하는, 넷플릭스 다큐/애플 키노트 오프닝 같은 10초 세로 원샷.
핵심 규칙: **단 하나의 연속 카메라 무브. 장면으로 생각하지 않는다.**

## 핵심 결정 — 진짜 단일 씬

이전 hero는 6개 씬(매치컷)이라 경계가 존재했다. 이번엔 **전체 10초를 물리적으로 하나의 씬**으로
만들었다(요소 98개, 컷 0개). 그래서 "이제 새 장면"이라는 느낌이 원천적으로 불가능하다. 오브젝트는
공유 중심(CX, CY)에서 시간축을 따라 손을 넘기고(handoff), 카메라(keyframe scale)는 10초 내내 멈추지
않으며, 큰 전환은 페이드가 아니라 **요소가 렌즈를 지나며 커지는 zoom-through**로 처리했다.

## 변형 체인 (전부 한 타임라인, 공유 중심)

별 → 시계 나사 → 기어 → 파이차트 → (구멍 통과) → 라인차트 → Apple 로고 → 유리 빌딩(반사) →
대시보드 → 입자 상승 → $8,000,000(화면 채움) → 폭발/되감기 → 시계 → 한 번의 초침 → 검정.
모든 것이 시계 안에서 일어났다는 회수(rewind)로 수미상관.

## 산출물

- **엔진 원샷**: `oneshot/oneshot-connected/output.mp4` — 1080×1920/30fps/10s/300f/0.46MB/moov✓.
- **하이브리드**: `scratchpad/oneshot_hybrid.mp4` — 전체 필름을 잔잔한 분위기 영상(물결 스탠드인) 위에
  합성. 하나의 영상이 밑에 깔려 AI↔엔진 경계를 은폐한다(WAN 클립으로 교체 가능).

## 자기검토

- 다시 볼 만한가? **예** — 밀도 높고 끊김 없음.
- Hero video로? **예**.
- 애니메이션이 아니라 연출된 느낌? **예** — 명확한 여정, 의도된 컷 0.
- 매초가 존재를 정당화? **대체로 예** (구멍 통과 ~0.4s가 가장 약함 — 의도된 "안으로" 비트).
- 2초마다 놀람? **예**: 별→시계 / 기어→차트 / 차트→Apple / Apple→빌딩 / 대시보드→입자 / 입자→$8M / $8M→시계.
- "한 번도 멈추지 않았다"? **예** — 단일 씬, 컷 없음, 연속 스케일.
- AI↔엔진 경계 은폐? 하이브리드에서 하나의 분위기 영상을 전역으로 깔아 실증.

## 정직한 한계

WAN 생성 도구가 이 환경에 없어 감정 비트(시계 매크로·기어·입자·유리 반사·럭셔리 라이팅)를
실사 AI로 만들지 못했다. 대신 도형/입자/스큐 패널로 스타일화했고, 하이브리드 합성 경로로 실사
영상 위 합성을 실증했다. Apple 로고는 추상 원형 스탠드인. 진짜 최상급은 WAN 클립 + 가우시안
글로우 후처리가 더해질 때 완성된다.
