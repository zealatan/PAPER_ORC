# One Legendary Moment — 리포트 (Director Challenge #003)

목표: 영상이 아니라 **하나의 잊히지 않는 순간**. 사람들이 정보를 놓쳐서가 아니라 "저 전환이
어떻게 가능하지?" 때문에 즉시 재생 버튼을 누르게 하는 것. 전체 10초는 **하나의 히어로 프레임 +
하나의 히어로 초**를 위해 존재한다.

## 히어로 프레임 (포스터)

`$8,000,000`을 품은 **기념비적 구조물** — 발광하는 코어(태양) + 3개 동심 궤도 + 궤도 위 데이터
노드 + 방사 눈금, 대칭·큰 여백. 블룸 그레이드로 "코스믹 리액터"처럼 발광한다. GitHub 배너 /
랜딩 히어로 / 썸네일 / 키노트 오프닝 슬라이드 — 네 조건 모두 충족. `LEGEND_HERO.png`.

## 히어로 초 (7.0–8.0s)

구조물이 완성되어 카메라가 **느려지고 머무는** 1초. 앞의 7초(글린트→시계→구멍 진입→코어 등장)는
전부 이 순간의 기대를 쌓고, 뒤의 2초(붕괴)는 관객이 숨 쉬게 한다.

## 서사 — 하나의 오브젝트 속을 여행

관객은 시계 하나를 본다고 믿는다. 카메라가 시계 안으로 날아들고(구멍=터널, 컷 없음), 안에서 기어
→ 구조 → 데이터 → 빛 → 금융 우주로 변한다. 끝에서 그 기념비적 우주가 붕괴하며 **시계 안으로**
빨려 들어간다 — 처음부터 시계 안이었다. 초침 한 번. 검정.

## 재설계 (튜닝 아님)

- 히어로를 "$8M 텍스트"에서 **기념비적 대칭 구조물**로 새로 설계 — 차트/숫자가 아니라 오브젝트.
- 단일 씬(컷 0) + 패럴랙스 깊이 + zoom-through(구멍/붕괴) → 물리적으로 하나의 카메라.
- 후처리 시네마 그레이드(블룸+비네트+그레인)로 벡터를 렌즈로. `output_graded.mp4`(0.48MB).

## 절대 규칙 준수

컷 없음 / 페이드 전환 없음 / 무작위 줌 없음 / 무에서 등장 없음(모든 것은 이미 존재한 것에서 변형:
글린트→시계, 시계 구멍→터널→우주, 우주→시계). 매 프레임이 다음으로 자연히 이어진다.

## 최종 질문

"제목·로고·설명이 없어도 내일 이 영상을 기억할까?" — **예**. 발광하는 코스믹 리액터 프레임은
스크린샷하고 싶은 이미지다.

## 정직한 한계 (WAN)

WAN 생성 도구가 없어 시계 매크로·금속 기어·유리 반사·연기·광선을 실사로 만들지 못했다. 도형+블룸
그레이드로 근사(오브가 광원처럼 발광). 진짜 최상급은 P2 시계 매크로에 WAN 클립을 배경으로 깔고
동일 그레이드를 얹을 때 완성 — 그레이드가 AI↔엔진 경계를 통일한다.
