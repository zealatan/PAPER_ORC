# One Impossible Camera Shot — 리포트

목표: 영상이 아니라 **하나의 잊히지 않는 카메라 샷**. 10초 전체가 컷 없는 불가능한 롱테이크로
느껴지고, "이거 어떻게 만들었지?"가 나와야 한다. 최종 테스트: 무음으로 봐도 _소프트웨어가 기능을
보여주는 게 아니라, 감독이 이야기를 들려주는_ 느낌인가.

## 두 가지 재설계 결정 (튜닝 아님)

1. **진짜 단일 씬 + 패럴랙스 깊이 + 전경 오클루전**
   - 10초 = 물리적으로 하나의 씬(컷 0). 오브젝트가 공유 중심에서 시간축을 따라 손을 넘긴다.
   - 깊이 레이어 3장을 **서로 다른 속도로 스케일**(near 1.0→1.2, mid 0.9→1.45, far 0.8→1.9) →
     진짜 3D 패럴랙스 심도.
   - 페이즈 전환마다 **큰 어두운 형태가 렌즈를 지나며 커진다**(occlusion) → 카메라가 물체를
     통과/지나가는 느낌. 페이드·슬라이드·컷 없음, 오직 통과와 변형.

2. **시네마틱 그레이딩 (엔진 밖 후처리 — software→cinema의 결정타)**
   평면 벡터를 "렌즈로 촬영한 화면"으로 바꾸는 최대 지렛대. 렌더 후 ffmpeg 1패스:
   ```
   ffmpeg -i output.mp4 -vf "split[base][b];[b]gblur=sigma=15[bl];
   [base][bl]blend=all_mode=screen:all_opacity=0.42[bloom];
   [bloom]vignette=angle=PI/4.5,eq=contrast=1.10:saturation=1.10:brightness=-0.012,
   noise=alls=4:allf=t" -c:v libx264 -pix_fmt yuv420p -crf 26 output_graded.mp4
   ```
   블룸(글로우)로 발광하는 오브가 진짜 광원처럼, 비네트로 시선 집중, 그레인으로 필름 질감.

## 카메라 여정 (별→시계→기어→차트→로고→입자→$8M→통과→시계, 한 타임라인)

Phase1 별/발광 입자 → 시계 나사 / Phase2 기어 → 파이·바 → 구멍 통과 / Phase3 라인차트 위를
달리며 로고가 세계 안에 등장 / Phase4 위로 발사, 입자가 모여 **$8,000,000**(히어로 프레임) /
Phase5 숫자를 **통과** → 시계만 남고 → 초침 한 번 → "Time built everything." → 검정.

## 산출물

- **그레이드 필름**: `impossible/impossible-shot/output_graded.mp4` — 1080×1920/30fps/10s/**0.48MB**.
- **원본(그레이드 전)**: `output.mp4` — 대조용.
- **히어로 포스터 프레임**: `$8,000,000` @7.7s — GitHub 배너/홈 히어로/썸네일/포스터로 바로 사용 가능.

## 자기검토 / 최종 테스트

- 다시 볼 만한가 / Hero video로 / 연출된 느낌 / 매초 정당화 — **예** (그레이드로 시네마 질감 확보).
- 소프트웨어인가 시네마인가 — **시네마**. 블룸·비네트·그레인 + 단일 씬 연속 + 오브젝트 핸드오프로,
  기능 나열이 아니라 시간을 여행하는 한 컷으로 읽힌다.
- 히어로 프레임 규칙 — **충족**: $8,000,000 프레임(발광 숫자 + 입자 후광 + 큰 여백)은 포스터급.
- 감정 곡선(호기심→경이→발견→규모→침묵→기억) — 각 페이즈에 매핑.

## 정직한 한계 (WAN)

이 환경엔 WAN 생성 도구가 없어 감정 비트(시계 매크로·금속 기어·유리 반사·연기·광선)를 실사로
만들지 못했다. 대신 도형+블룸 그레이드로 근사했고(오브가 광원처럼 보이는 효과), 하이브리드 합성
경로는 이미 실증돼 있다(hero/oneshot). 진짜 최상급은 WAN 매크로 클립을 배경으로 깔고 같은
그레이드를 얹을 때 완성 — 경계는 그레이드가 통일해 준다.
