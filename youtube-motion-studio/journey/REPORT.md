# The Journey of Time — Director's Challenge 리포트

목표: "After Effects로 만든 줄 알았다" 수준의 **대표 시네마틱 필름**. 기능 데모가 아니라, 스토리와
연출만으로 엔진의 잠재력을 증명하는 쇼릴. 새 엔진 기능은 만들지 않았다.

출력: `1080×1920 / 30fps / H.264 / yuv420p / 무음`, **74초 / 2220프레임 / 2.55MB / moov 정상**.

## 5개 챕터 (하나의 아크, 시계로 수미상관)

1. **Time** (0–10) — 정적·여백·긴장. 시계가 태어난다.
2. **Time becomes Data** (10–28, 18s 롱테이크) — 시계 → 도넛(68%) → 카메라가 차트 속으로 → 숫자.
3. **Data becomes Companies** (28–44) — 세계지도 연결선 → 도시점이 로고로 → 사진 병합 → 카드가 배경으로.
4. **Companies become Wealth** (44–60) — 주가·배당 차트 → 스큐된 "복리"(3D 오브젝트) → 숫자 폭발 $8M.
5. **Everything returns to Time** (60–74) — 카메라 풀아웃, 처음의 시계만 남는다. "It was time."

## 연속성·전환 (페이드 반복 금지)

카메라·모프·크로스씬 합성이 엔진에 없어, **매치컷**으로 연속감을 만들었다: 컷 경계에서 도형의
위치·크기를 일치시키고 키프레임 scale로 모멘텀을 이어받게 하면, 하드컷이 페이드가 아니라 모프/
푸시스루로 읽힌다. 매 챕터 다른 전환:

- Ch1→2: 시계 원이 그대로 도넛으로 (원→도넛 모프, scale match)
- Ch2→3: 숫자가 화면을 채우며 줌스루 → 지도 (number zoom-through)
- Ch3 내부: 도시점→로고(위치 매치), 사진 4장→한 패널로 병합, 카드가 확대되어 다음 배경이 됨
- Ch3→4: 카드 색 = Ch4 배경색 (card becomes background)
- Ch4: 숫자 폭발(발광 디스크 확장) — number explosion
- Ch4→5: 폭발 후 검은 공간으로, Ch5는 카메라 풀아웃
- Ch5=Ch1: 동일 시계 링 (clock bookend)

- [x] 숫자가 화면을 가득 채운다 (Ch2 $1.24M, Ch4 $8M)
- [x] 사진 여러 장이 하나로 합쳐진다 (Ch3)

- [x] 카드가 다음 장면의 배경이 된다 (Ch3→4)
- [x] 텍스트가 공간 속 오브젝트처럼 (Ch4 스큐된 "복리")
- [x] 15초 이상 롱테이크 (Ch2 = 18초 연속)

1. 놀랄 장면 3개+? — 원→도넛, 숫자 줌스루→지도, 카드→배경, 숫자 폭발, 스큐 복리, 시계 수미상관 → **예**

## 정직한 한계 (다음 기능이 있으면 더 올라간다)

매치컷·scale로 카메라를 흉내냈지만 진짜 카메라 레이어(팬/오빗/달리/패럴랙스)·모션블러·가우시안
글로우·실사진·네이티브 모프는 없다. 필요 순서: ①이미지 에셋 ②카메라 레이어 ③장면전환 합성
④블러/글로우 필터 ⑤위치·회전 키프레임.

## 기술 메모

타임라인은 애니메이션에 `sceneLocalTime − timing.start`(element-상대)를 넘긴다. 따라서 타이밍 창이
있는 요소는 애니 start를 0(탄생 시점)으로 줘야 한다. 이 규칙 위반이 초기 렌더에서 로고·복리가
안 보인 원인이었고, element-상대로 전면 수정해 해결했다.
