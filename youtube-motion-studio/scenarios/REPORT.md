# YouTube Motion Studio — Cinematic Scenarios 리포트

목표: 기능 테스트가 아니라 **유튜브에서 실제로 쓸 수 있는 5~8초 시네마틱 Shorts**. 스토리와
연출로 엔진의 표현력을 보여주는 데 집중했다. 새 엔진 기능은 만들지 않고 우회·조합·디자인으로만.

출력: 전부 `1080×1920 / 30fps / H.264 / yuv420p / 무음`. 디자인 규칙 준수(검정 배경 · 흰 타이포 ·
노랑 포인트 · 한 화면 하나의 메시지 · 첫 2초 훅). 갤러리 `scenarios/gallery/index.html`.
각 폴더: `project.json` `output.mp4` `poster.png` `contact-sheet.png` `validation.json`.

## 2. 연출을 위해 "엔진에 없는 효과"를 우회한 방식

절대 원칙(새 기능 금지). SVG 백엔드가 렌더하지 않는 효과를 **디자인·타이밍·조합**으로 연출:

| 연출 의도              | 엔진 한계        | 우회                                                          |
| ---------------------- | ---------------- | ------------------------------------------------------------- |
| 화면 흔들림 (03)       | 위치 애니 없음   | **초단(0.1s) 장면 3컷**에 숫자를 좌우로 오프셋 → 잔상 셰이크  |
| 플래시 (03)            | 없음             | **0.13초 흰색 그라디언트 장면** 삽입 → 컷 충격                |
| 파티클/동전 분해 (01)  | 파티클 없음      | 18개 노랑 dot을 stagger pop → "동전" 군집                     |
| 글로우 (01·02·04·07)   | 블러 없음        | 큰 반투명 노랑 dot/panel을 텍스트 뒤에 → 유사 발광            |
| 카메라 푸시 (05·08·10) | 카메라 없음      | **풀블리드 그라디언트 패널 + 키프레임 scale** → 밀려드는 느낌 |
| 반사 (05)              | 없음             | 제품 패널 아래 저투명 미러 패널                               |
| 시계 회전 (01)         | 회전 애니 없음   | 바늘을 다른 각도로 **타이밍 컷** → 째깍                       |
| 사진/이미지 (02·06)    | 이미지 에셋 없음 | 그라디언트 액자 패널 + Ken Burns 줌                           |
| 장면 디졸브 (06)       | 하드 컷          | 요소 fade in/out으로 크로스페이드 감                          |
| 블러/모션블러 (09 등)  | 없음             | 생략(대신 scale·slide·tilt·timing으로 리듬)                   |

→ 이 우회들로 "이 장면 어떻게 만들었지?" 인상을 낼 만큼의 연출이 나온다. 다만 진짜 고급 룩
(가우시안 글로우·실사진·디졸브·모션블러)은 아래 기능이 있어야 완성된다.

## 3. 가장 완성도 높은 영상

- **03 Stock Crash** — 초록 급등 → 흰 플래시 → 셰이크 → 붉은 급락 → "배당은 계속됐다". 엔진에
  없는 shake/flash를 컷 편집으로 만들어낸, "어떻게 만들었지?"가 가장 강한 클립.
- **08 Future** — 연도가 바뀌며 배경이 카메라 푸시로 밀려드는 미래감 + 마무리 질문 카피.
- **10 Ultimate Reel** — 8초에 CREATE·차트·대시보드·타임라인·숫자·제품·브랜드를 컷으로 몰아친
  엔진 홍보 릴.

## 4. 앞으로 필요한 기능 (연출 관점 Top 10)

1. 이미지/사진 에셋 파이프라인 2. Gaussian Blur / Glow / Drop Shadow 필터
2. 장면 전환 합성(디졸브·와이프·딥투블랙) 4. 위치·회전 키프레임(셰이크·궤도·회전)
3. 카메라 레이어(줌·팬·푸시를 장면 전역에) 6. 파티클/에미터(동전·빛)
4. 숫자 카운터 컴포넌트(시간 인식) 8. 텍스트 자동 줄바꿈·리치텍스트
5. 모션 블러/셔터 10. 마스크·클립 리빌(라인 draw-on)

## 5. 재현

```
pnpm scenarios:all               # generate→preview→render→validate→gallery
pnpm scenarios:all --skip-existing
```
