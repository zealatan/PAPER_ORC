# YouTube Motion Studio — Ultimate Showcase (90초 필름)

목표: "이거 After Effects로 만든 거야?" 소리가 나올 만한 **한 편의 시네마틱 쇼릴**. 예제 모음이
아니라 하나의 예고편처럼 이어지는 90초 필름. 기능을 설명하지 않고, 스토리와 연출로 엔진의
표현력을 증명한다. 새 엔진 기능은 만들지 않았다.

출력: `1080×1920 / 30fps / H.264 / yuv420p / 무음`, **92.2초 / 2766프레임 / 1.92MB / moov 정상**.
스타일: Apple × Bloomberg × MagnatesMedia × Netflix. 색: 검정 · 흰 · 노랑. 렌더 ~79초(장면 병렬).
파일: `ultimate/ultimate-90/` — `project.json` `output.mp4` `poster.png` `contact-sheet.png`
`validation.json`. 갤러리 `ultimate/gallery/index.html`.

## 엔진에 없어 우회한 연출 (새 기능 금지 원칙)

| 의도                      | 엔진 한계             | 우회                                           |
| ------------------------- | --------------------- | ---------------------------------------------- |
| 카메라 줌/패닝/푸시       | 카메라 레이어 없음    | 요소·풀블리드 패널에 키프레임 scale            |
| 장면 전환(디졸브)         | 크로스-장면 합성 없음 | dip-to-black 패널 페이드 + 요소 fade in/out    |
| 글자 통과(카메라 through) | 없음                  | 텍스트 scale 1→2.2 + fade out                  |
| 시계 회전                 | 회전 애니 없음        | 바늘을 각도별 타이밍 컷                        |
| 세계지도 연결선           | 라인 프리미티브만     | 회전한 얇은 패널 = 도시 간 링크                |
| 도넛 차트                 | 도넛 없음             | 동심원(circle) 링 + % 라벨 게이지              |
| 사진/이미지               | 이미지 에셋 없음      | 액자 패널 + 피사체 실루엣 + 발광 dot(스타일화) |
| 파티클/글로우/블러        | 필터 없음             | 반투명 레이어 dot/panel                        |

→ 이 우회들로 "예제 모음"이 아닌 예고편 리듬을 냈다. 다만 진짜 최상급(가우시안 글로우·실사진·
카메라 레이어·디졸브·파티클)은 아래가 있어야 한다.

## 다음 기능 (이 필름을 한 단계 더 올리는 순서)

1. **이미지 에셋 파이프라인** — S7 실사진, S4 실제 로고, S3 실제 지도.
2. **카메라 레이어**(장면 전역 줌/팬/푸시) — 지금은 요소별 scale로 흉내.
3. **장면 전환 합성**(디졸브·와이프·딥투블랙 네이티브).
4. **Gaussian Blur / Glow / Shadow 필터**.
5. **위치·회전 키프레임**(궤도·스핀·셰이크).
6. 파티클/에미터, 7. 도넛/게이지 차트, 8. 숫자 카운터, 9. 모션 블러, 10. 마스크·클립 리빌.
