# Time Creates Wealth — Hero Video (10s) 리포트

목표: 10초 동안 지루하지 않은, "이거 어떻게 만든 거지?" 소리가 나오는 Hero Video.
원칙: AI가 감정, 엔진이 정보.

## 산출물

- **엔진 필름**(정보·모션그래픽 레이어): `hero/hero-video/output.mp4` — 1080×1920/30fps/10s/300f/0.41MB/moov✓.
- **하이브리드 합성 증명**: `scratchpad/hero_composite.mp4` — 엔진 그래픽을 실사 시간영상(모래시계
  스탠드인) 위에 합성. WAN 클립을 넣으면 그대로 대체된다.
- **AI 샷리스트**: `hero/AI_SHOTLIST.md` — WAN 프롬프트 5개 + 합성 지침.

## 10초 모프 체인 (Fade 반복 금지, 매치컷 연결)

점 → 시계(푸시인) → 기어 → 원형 데이터 그리드 → 차트(카메라 진입) → 로고 체크포인트 →
입자 수렴 → $8,000,000(화면 채움) → 산산조각 → 입자 재조립 → 시계(수미상관) → "It was time."

각 전환은 도형이 다른 도형으로 변하는 매치컷: 점=시계중심, 기어원=그리드, 입자=숫자, 숫자파편=시계.

## AI(WAN) 사용 — 정직한 상태

이 환경엔 WAN 생성 도구가 없어 AI 클립을 직접 만들지 못했다. 대신:

- 감정 비트(시계 클로즈업·기어·입자·빛)를 **비디오 배경 슬롯**으로 구조화했고,
- 엔진의 **비디오 합성 경로**(`exportVideo` overlay, PG 덱에서 검증)로 **스탠드인 영상 합성을 실증**했다
  (`hero_composite.mp4`). WAN 클립을 `hero/bg/`에 넣고 씬 배경을 video로 바꾸면 끝.

## 자기검토 5문항

1. 영화 예고편처럼 보이는가? — **예** (10초 압축 아크, 매치컷).
2. 카메라가 살아있는가? — **예** (매 비트 kenBurns push/pull + 매치컷; 진짜 오빗/달리는 WAN/후처리 몫).
3. AI와 모션그래픽이 하나의 세계인가? — **부분→예**: 배송된 엔진 필름은 엔진-온리지만, 하이브리드
   합성을 실제 영상으로 증명함. WAN 클립을 넣으면 완전한 하나의 세계가 된다.
4. 10초 안 가장 강렬한 장면? — **예**: 돈이 부서져 입자로, 입자가 다시 시계로 모이는 순간.
5. Hero Video로 부끄럽지 않은가? — 엔진-온리로도 **예**; WAN 합성 시 더 강해짐.

정직: 3번이 완전한 "예"가 되려면 WAN 클립이 필요하다 — 파이프라인·프롬프트는 준비 완료.
