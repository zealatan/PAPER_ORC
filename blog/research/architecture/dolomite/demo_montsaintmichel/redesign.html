307샷 역추론 규칙집(mechanism·common-technique·answerkey·diorama-anatomy)을 근거로, 데모가 왜 못 미쳤고 어떻게 레퍼런스급으로 끌어올릴지의 블루프린트.

01반성 — 왜 아쉬웠나

핵심 실책: "프롬프트를 썼다". 해야 했던 건 역추론된 함수 f를 적용하는 것이었다.

분석 문서엔 f = STYLE_BASE + archetype(role) + render(object+action) + composition 이 307샷으로 검증돼 있는데, 데모는 이 규칙 대신 매 샷 즉흥으로 장면을 상상했다.

R3 · 오버레이 색코딩 사전 (후반 합성 · red 70 : cyan 13)

문제 = 붉음/어둠
  • 붉은 치수선·화살표 (하중·방향·힘)
  • red 측정 그리드 / 각도 마커 / 경사 화살표
  • red 응력-발광(stress-glow) · 압력/무게 하강 화살표
  • red 침식 라인 · 수렴 화살표 · 위험 마커
  • white 스피드라인 (radial/speed) — 속도·긴장
해법 = 파랑/청록 발광
  • cyan/blue 흐름선 (물·배수·방류)
  • glowing 네트워크 라인 · 배수망 그리드
  • cyan 구역 박스 순차 점등 / 윤곽 발광
  • 파란 컷어웨이(물/냉) · 오렌지 컷어웨이(열/불)
  • 등고선 오버레이 · 발광 outlet 링 · 반투명 버블

공통: 대형 키워드 자막(중앙) · 숫자 초대형 단독 배치(5만·156m·240개·98m) · 사람 실루엣(스케일) · 지도+거리 라벨 · ✦ 스파클 트랜지션(우하단) · 고정 클로징 "…이렇게 탄생한 겁니다".

컷 시퀀스 문법 (10편 공통 순서)

실사 부감 → 클로즈업 → 컷어웨이 단면 → 물리시뮬 기각샷 → 스피드라인 전환 → 익스플로디드/아이소 → top-down 순차점등 → 발광 네트워크·지도 → 실사 오빗 클로징

파이프라인 (자동화)

주제 → ① LLM 7비트 대본 → ② 컷 분해(1문장→1~2샷·~3.5s) → ③ t2i 스틸(Flux) → ④ i2v 모션(LTX) → ⑤ 자막·오버레이(PIL/CapCut) → 쇼츠.
핵심: ③④ 2단이 원본 재현·정확도의 열쇠. 로컬 ai_diorama(Blender→Flux→LTX)와 동일 구조.

부유 디오라마 해부 (시그니처)

세상 한 조각을 잘라 어두운 허공에 띄움 → 잘린 단면=지층 머티리얼 → boolean로 속 파냄(집수정·수로) → 측·바닥 평평(표본감) → 아래 블러그림자+배경간격=부유감 → 45°키+안개+AO → Empty 오빗·DOF·손떨림. 재사용 리그(RIG_LIGHTING/CAMERA/POST)로 편당 '주제 모델링'만.

04발산 — 새 아이디어 (현재 23컷 밖)

모티프 신규

  • 조석 게이지: 하루 조위 곡선 위 밀물/썰물 포인트가 달리는 HUD (14m 진폭)
  • 퇴적 네트워크 지도: 조류·강물 벡터가 발광 라인으로 섬으로 수렴 (문제) → 방류로 역전(해법)
  • before/after 와이프: 갯벌에 묻힌 섬 ↔ 물에 뜬 섬 슬라이더
  • 수문 8개 순차 점등: 방류 순간 게이트가 좌→우 순차 발광

서사·비유 강화

  • 콜로세움의 "해군 불러옴"처럼 — 몽생미셸 공법/인력의 의외의 디테일 1컷
  • 스케일 비유는 사람 실루엣 우선(채널 시그니처), 축구장·수영장·아파트는 보조
  • fail 3연타 리듬: 시도→기각→시도→기각 (준설·둑보강)
  • 클로징 고정 문구 통일: "…이렇게 다시 섬이 된 겁니다"

05다음 액션 (택1)

A. 정공법(레퍼런스 재현) — 오버레이 후반 분리 + t2i→i2v. AI는 깨끗한 씬만, red/cyan·숫자·게이지는 편집 레이어. → 레퍼런스급 정확도·룩. (작업량↑, 후반 필요)

B. baked 유지 + 기법만 주입 — 위 매트릭스의 아키타입·fail 기각샷·flip 청사진·컷어웨이 발광·색코딩을 프롬프트에 녹임. 숫자는 여전히 흔들릴 수 있음. (한 방, 정확도 타협)

C. 하이브리드 — 씬·발광 모티프는 baked, 숫자·치수선·게이지만 후반. (정확도 확보 + 작업량 중간) ← 실무 추천
