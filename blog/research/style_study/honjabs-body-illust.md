# 혼잡스 본문 일러스트 학습 — 전체 어휘 + 재현 레시피

> 대상: 혼잡스 영상 **본문(내레이션) 그림들**. 썸네일과 같은 클린 흑백 웹툰 라인아트지만, 캐릭터 외에 **손·미니피규어·소품·로봇 등 스팟 일러스트 어휘**가 풍부.
> 코퍼스: top1·2·3 영상에서 3초 간격 301프레임 → 자동 선별 **180프레임**(`body_corpus/`). 화면녹화·붓글씨·AI사진 제외.
> 화풍 기본 규격·프롬프트는 [[honjabs-style]](honjabs-style.md) 참조. 여기선 **본문 어휘와 구성 방식**을 다룬다.

## 1. 본문 그림의 구성 방식 (핵심 발견)
혼잡스 본문은 "말하는 사람 영상"이 아니라 **일러스트 슬라이드 + 화면녹화의 교차**다.
- **내레이터 캐릭터**가 화면 한쪽(주로 우측)에 서서 말하고, 반대쪽에 자막.
- 설명이 실전으로 넘어가면 **지시봉(포인터 막대) 든 손**이 화면녹화를 가리키며 연결 → 일러스트↔스크린을 자연스럽게 잇는 시그니처 장치.
- 개념·은유는 **스팟 일러스트**(미니 피규어·소품)로 순간 삽입.
- 전부 동일한 얇은 검정 라인·순백 배경 → 톤 일관성이 채널 정체성.

## 2. 어휘 카탈로그 (180프레임에서 분류)
| 그룹 | 요소 | 용도 |
|---|---|---|
| **캐릭터** | 무표정 상반신 / 손가락 가리키기 / 엄지척 / 제지(손바닥) / 팔짱 / 놀람(뺨에 손) | 내레이션 주체·감정 |
| **지시봉 손** | 긴 얇은 막대 든 손이 UI를 가리킴 | 일러스트→화면녹화 연결(최다) |
| **물건 든 손** | A4 종이 / 스마트폰 촬영 / 펜 / 카메라 | 실물 부업 행위 묘사 |
| **미니 피규어** | 자는 사람(Zzz) / 책상 3인 / 군중 만세 / 발표대+청중 / 돈 낚시 | 상황·은유 |
| **돈/소품** | 현금다발+동전 / 대형 "100"·"10만원" 타이포 / 상점(다이소) / 파일아이콘(PNG·JPG) / Control+C 키 / 좋아요·유튜브 버튼 | 수익·도구 은유 |
| **AI 로봇** | 둥근 몸통의 귀여운 라인 로봇(엄지척·반짝이) | AI 도구 은유 |
| _제외_ | 붓글씨 타이포(폰트) · 화면녹화 · AI생성 사진 | 학습 대상 아님 |

## 3. 재현 레시피 (`gen_body_vocab.py`)
STYLE 프리픽스는 [[honjabs-style]]와 동일. **두 모드**로 생성:
- **캐릭터 모드**: `STYLE + CHAR + "<제스처>, empty space on left"` (내레이터)
- **스팟 모드**: `STYLE + "<요소> isolated line-art icon centered on white, no text"` (CHAR 없이 단독 아이콘)

**검증 시드**(재현물 `vocab/`):
- 캐릭터: 가리키기 `401` · 엄지척 `402` · 제지 `403`
- 손: A4 `411` · 폰촬영 `412` · 지시봉 `413`
- 피규어: 자는사람 `421` · 군중 `422` · 발표대 `423`
- 소품: 로봇 `431` · 현금다발 `432` · 상점 `433`

핵심 요령
- 스팟 아이콘은 반드시 `isolated ... centered on white, no text`로 배경·텍스트 억제.
- 지시봉·좋아요·바코드·대형 타이포는 **생성보다 벡터 합성이 더 안정적**(혼잡스도 별도 레이어). 애매하면 PIL/SVG로.
- 로봇·미니피규어는 Flux가 잘 뽑음 → 생성 채택.

## 4. 파이프라인 제안 (본문 그림 자동화)
1. 대본(스토리보드 `script`)을 씬별로 끊고, 각 씬에 **어휘 태그** 부여(캐릭터-가리키기 / 손-A4 / 로봇 …).
2. 태그→시드 매핑으로 `gen_body_vocab.py` 배치 생성 → 씬 일러스트 확보.
3. 화면녹화가 필요한 씬은 지시봉 손 레이어를 위에 합성.
4. 자막·대형 타이포·바코드는 합성 단계(PIL).
→ 스토리보드만 있으면 본문 일러스트를 반자동으로 찍어내는 구조.

## 5. 남은 갭 / 다음 단계
- 얼굴 웹툰화·넥타이 검정 고정은 [[honjabs-style]] §4 튜닝 노트와 동일.
- 미니피규어·로봇의 라인 두께가 캐릭터와 미세하게 다를 수 있음 → 후처리 라인 정규화 or LoRA로 통일.
- **LoRA 학습 권장**: `body_corpus/` 180장이면 캐릭터+스팟을 한 화풍으로 묶는 소형 LoRA 학습에 충분. 붓글씨·화면녹화 프레임만 추가 제거 후 사용.
