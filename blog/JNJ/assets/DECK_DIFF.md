# DECK_DIFF — 코카콜라 완성덱 ↔ JNJ 제작중 덱 씬별 비교

> 대상 파일
> - 코카콜라(완성·게시): `ref/cocacola_deck_dubbed.EXAMPLE.json` — **31씬 / 총 402초(6.7분)**
> - JNJ(제작중): `deck/jnj_deck.json` + `spec/narration_draft.json` — **18씬 / 총 226초(3.8분)**
> - 맥락: `HANDOVER.md §0.5` — JNJ는 회사소개·사업개요·시점분석을 의도적으로 컷하고 백테스트 3부 중심으로 축약(12분→5~7분 목표).

## 핵심 요약 (먼저 읽기)

1. **JNJ는 백테스트 3부는 잘 살렸지만 "축약"이 목표(5~7분)를 넘어 과축약(3.8분)됐다.** 코카콜라 31씬 → JNJ 18씬. 특히 코카콜라의 **긴장 2막(닷컴버블 시점위험 4씬 + survheat 생존지도)** 과 **사업개요 6씬 전체**가 통째로 빠지면서, JNJ 2부가 "차트 4장 나열"로 평탄해졌다.
2. **가장 큰 방법론 차이: 코카콜라 FIRE 헤드라인은 전부 [물가 반영]인데 JNJ 헤드라인은 [명목]이다.** 코카콜라는 물가반영으로 "다 파산한다"는 충격을 먼저 주고, JNJ는 명목으로 "꽤 살아남는다"를 보여준 뒤 물가를 **$200k 1씬만** 반전으로 붙인다. 감정 곡선이 약해졌다.
3. **시각 템플릿 다양성이 절반으로 줄었다.** 코카콜라 16종 tpl → JNJ 10종. JNJ가 안 쓰는 것: `survheat · regionmap · divbars · cupdrain · quad · checks` + 인트로용 `card`. 도입부가 herostat+kpirow 2씬뿐이라 코카콜라(herostat+card+solostory 등) 대비 빈약.
4. **JNJ는 interlude(전환 정지화면)를 4회로 코카콜라(3회)보다 많이 쓰는데, 씬7·8이 연속(hourglass_time bg 2연속)이라 26초간 텍스트-정지가 이어져 늘어진다.** 코카콜라는 같은 자리를 실제 콘텐츠 씬으로 채웠다.
5. **JNJ가 더 나은 점도 있다**: ① 훅영상을 맨 앞(씬0)에 배치(코카콜라는 notice 뒤), ② A/B 원금을 **똑같이 $400k**로 통일해 "생활비 차이만"이라는 메시지가 더 깔끔, ③ 3부에 명목 부분을 이미 정리. 이 강점은 유지할 것.

## 2. tpl(템플릿) 사용 차이

**코카콜라 사용 tpl = 16종**
`notice · videohook · solostory(×4) · interlude(×3) · herostat · card(×2) · enginechart(×9) · survheat · regionmap · divbars · cupdrain · kpirow · quad · checks · hbars2 · quotebig`

**JNJ 사용 tpl = 10종**
`videohook · notice · solostory(×2) · interlude(×4) · herostat · kpirow · enginechart(×5) · hbars2 · quotebig · card(×1)`

**JNJ가 안 쓰는 tpl 6종 (+card 인트로 용법)**

| tpl | 코카콜라 용도(씬) | JNJ 컷 정당성 |
|---|---|---|
| `survheat` | 14 — $원금×월인출 3×3 **생존지도**(초록/노랑/빨강), 2000·2002 두 격자 | ⚠ **재고 권장**. §0.5도 "옵션"으로 남겨둔 것. 2부 차트 3~4장의 결론을 한 장으로 요약하는 강력한 페이오프. 시점위험은 빼더라도 생존지도 1씬은 값어치 큼 |
| `regionmap` | 16 — 지역별 매출 비중 세계지도 | ✅ 사업개요, §0.5대로 컷 타당 |
| `divbars` | 17 — 64년 연속 배당인상 막대 | △ **배당왕 앵글은 JNJ의 핵심 셀링포인트**. herostat(씬5)에서 "64년"만 텍스트로 언급하고 넘어감. 시각화 1씬 추가 여지 |
| `cupdrain` | 18 — 배당성향 67% 게이지 | ✅ 컷 타당(단 배당지속성 한 줄 언급은 kpirow에 있음) |
| `quad` | 20 — 4칸 브랜드 그리드 | ✅ Kenvue 분사로 "브랜드" 앵글 무효, 컷 타당 |
| `checks` | 28 — 매수 전 체크리스트(밸류/위험) | △ 결론 직전 "정리" 역할. quotebig(씬16)이 일부 대체하나 밸류에이션·리스크 고지가 사라짐 |
| `card`(인트로) | 6 — 대형 타이틀 카드(칩 3개: 주가/증배연수/시총) | △ JNJ는 card를 아웃트로(씬17)로만 씀. 도입 임팩트용 card 1씬 고려 |

**도입부 밀도 비교**: 코카콜라 종목소개 = herostat(규모) + card(타이틀+3칩) = 시각적으로 2가지 폼. JNJ = herostat(64년) + kpirow(매출타일 4개) = 무난하나 card의 "대문" 임팩트가 없음.

## 3. 흐름·페이싱 차이

**코카콜라의 긴장 설계 (기승전결이 뚜렷)**
- 기(훅): videohook 36초 대형 + solostory A/B로 인물 대비.
- 승(2부 전반): 7·8·9에서 $200k→$400k→$600k 물가반영, "다 파산/일부 생존"의 점층.
- **전(2부 반전): 10 닷컴버블 붕괴로 "그런데 시작 시점이 문제였다" 반전 → 11·12·13 2002재시작으로 "10년 더 버틴다" 뒤집기 → 14 survheat로 전체를 한 장에 수렴.** ← 이 2막이 영상의 하이라이트.
- 결(3부+마무리): 매수전략 → checks → quotebig → card.
- interlude 3회를 **섹션 경계**(4=훅후, 15=2부→사업개요, 21=사업개요→3부)에만 배치해 리듬 앵커로 사용.

**JNJ의 흐름 (평탄·전반부 정지 과다)**
- 기(훅): 코카콜라와 동일하나 videohook 17.5초로 절반. 훅 임팩트가 짧음.
- 인트로 후 **interlude 7(A/B결과 공개, 16.6초) → interlude 8(질문, 9.7초) 2연속** = 26초간 배경영상+텍스트만. 여기서 시청자가 이탈하기 쉬운 구간.
- 승(2부): 9·10·11 명목 + 12 물가($200k만). **반전 2막이 없어** 차트 4장이 같은 톤으로 나열 → 클라이맥스 부재.
- 결(3부): interlude 13 → enginechart 14(3전략을 한 씬에 합침) → hbars2 15. 압축은 잘 됨.
- interlude 4회 중 7·8이 인접해 "정지 2연타"가 페이싱의 최대 약점.

**정리**: JNJ는 "짧게"는 달성했으나 코카콜라식 **반전(전) 구조**를 통째로 버려 심장 박동이 밋밋. §0.5가 컷하라던 건 "닷컴버블 시점위험 설명"이지 "긴장 구조" 자체가 아니다 — survheat 한 장으로 긴장의 수렴점만 되살리는 게 최선의 절충.

## 5. JNJ가 코카콜라에서 가져오면 좋을 것 (위치·tpl 지정, §0.5 존중)

우선순위 순, 3.8분 → 4.5~5분(목표 하단)으로 밀도 보강:

1. **[강력추천] survheat 1씬 신설 — 위치: JNJ 씬12(물가연동) 뒤.**
   - 코카콜라 씬14 형태 차용하되 격자 1개(2000년)만: `rows:[$200k,$400k,$600k] × cols:[$1k,$2k,$3k]`, 셀=초록/노랑/빨강.
   - 2부 차트 4장(씬9~12)의 결론을 한 장으로 수렴 = 잃어버린 페이오프 복원. §0.5도 survheat는 "옵션"으로 허용.

2. **[추천] divbars 또는 herostat 강화 — 위치: 씬5~6 사이 또는 씬5 대체.**
   - "64년 연속 증배" 텍스트를 divbars(연도별 주당배당 막대)로 시각화 1씬. JNJ 정체성=배당왕을 눈으로 각인. 데이터는 배당 시리즈에서 결정론 산출 가능(HANDOVER §B).

3. **[중간] interlude 7·8 정지 2연타 해소.**
   - 씬7(A/B 결과 공개)을 정지 interlude 대신 **solostory 재등장 or 간이 2열 비교 카드**로 시각화하거나, 씬7·8을 1씬으로 병합. 26초 정지 → 12~14초로.

4. **[중간] 2부 헤드라인을 [물가반영]으로 통일 고려.**
   - 현재 씬9·10·11 명목 + 씬12만 물가. 코카콜라처럼 물가반영이 "다 파산"의 충격이 크고 현실적. 최소한 씬11($600k) 뒤에 물가반영 요약을 붙여 "명목으론 살지만 물가 넣으면 다르다"의 반전을 살릴 것. (survheat를 물가반영 격자로 만들면 3·4번 동시 해결)

5. **[선택] checks 또는 notice 보강 — 위치: 씬16(quotebig) 앞 or 씬1 notice.**
   - 밸류에이션/구조적 위험(예: JNJ 소송 리스크·성장 한계) 1줄 고지. 투자 정보물 균형.

6. **[선택] 도입 card 1씬 — 위치: 씬5 herostat 뒤.**
   - 코카콜라 씬6처럼 칩 3개(주가/증배연수/시총) 대문 카드로 도입 임팩트 보강. (아웃트로 card 씬17과 폼 중복이라 우선순위 낮음.)

> **하지 말 것**: regionmap·cupdrain·quad·2002재시작 3차트·닷컴버블 씬 복원 — §0.5 철학에 정면 배치. 컷 유지가 맞다.

## 6. 페이지별 상세 diff (씬 번호 단위)

- **KO 0 notice ↔ JNJ 1 notice**: 둘 다 면책. JNJ가 2줄로 간결(KO 3줄). JNJ는 videohook을 씬0으로 앞세워 **훅 먼저→면책 나중** = 시청 지속률에 유리. ✅ JNJ 개선.
- **KO 1 videohook(36s) ↔ JNJ 0 videohook(17.5s)**: 동일 tpl. JNJ가 절반 길이 = 훅 몰입 시간 짧음. subLines도 6줄(KO 15줄)로 압축. △ 조금 더 늘릴 여지.
- **KO 2·3 solostory(A/B) ↔ JNJ 2·3 solostory(A/B)**: 구조 동일. **차이: KO는 A=$600k/월$3k(더 많은데도 파산 2015), B=$400k/월$1k($717,425)** = 원금 다름(아이러니 강조). **JNJ는 A·B 모두 $400k 동일, 월$3k→2018파산 / 월$1k→$2,435,842** = "생활비만 다름" 순수 대조. ✅ JNJ가 교육적으로 더 깔끔. (accent 문구 형식 동일)
- **KO 4 interlude ↔ JNJ 4 interlude**: "26년 뒤 어떻게?" 동일 기능. bg만 soda_ice→water_ripple. ✅ 동등.
- **KO 5 herostat ↔ JNJ 5 herostat**: KO=하루22억잔(규모 앵글), JNJ=64년 증배(배당왕 앵글). 둘 다 num+label+sub. ✅ 앵글만 섹터에 맞게 교체, 적절.
- **KO 6 card ↔ JNJ 6 kpirow**: **여기서 갈림.** KO는 타이틀+3칩 대문 카드, JNJ는 매출타일 4개(제약$60.4B/의료$33.8B/총$94.2B/배당$5.36). 성격 다름 — JNJ는 실적, KO는 브랜딩. JNJ에 **card 대문이 없음** → 도입 임팩트 약화(§5-6).
- **JNJ 7·8 interlude (KO 대응 없음)**: JNJ 신설 A/B 결과공개+질문. 정지 2연속 26초 = 페이싱 약점(§3, §5-3).
