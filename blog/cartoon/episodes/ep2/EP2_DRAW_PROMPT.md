# EP2 만화 생성 프롬프트 — QQQ 일시매수 vs 분할매수 (2022 금리인상기)

> **용도**: 8컷(4×2) 만화 생성용 아트디렉션. 우리 백테스트 애니메이터가 **실데이터 그래프·모션그래픽을 얹을 "오버레이 슬롯"을 비워두도록** 설계했다. 슬롯 안에는 가짜 그래프·숫자를 그리지 말고 **깨끗한 빈 영역**(연한 테두리 박스)만 둔다.

## 실측 데이터 (오버레이가 채울 값 — 참고용, 그림엔 넣지 말 것)
- 종목 **QQQ**, 시작 **2022년 1월**, 종료 **2024년 3월(약 26개월)**
- 2022 저점(11월) **−34.8%**
- 최대낙폭: 일시매수 **−34.8%** / 분할매수(6개월) **−24.5%**
- 24개월 후 자산배수: 일시 **1.10배** / 분할 **1.28배**
- 원금 회복: 일시 **23개월** / 분할 **2개월**
- 분할 = 2022년 1~6월 매달 동일금액 6회

---

## 전체 스타일 규칙 (EP1과 통일)
- **캐릭터**: 흑백 라인아트, 둥근 얼굴 + 삐죽삐죽 짧은 머리, 검은 반팔티 + 남색 반바지, 흰 신발. 표정만 컷마다 변화(밝음→불안→슬픔→담담). EP1과 동일 인물.
- **배경**: 순백(#ffffff). 그림자·질감 최소.
- **레이아웃**: 4열 × 2행 = 8컷, 각 컷 **세로로 긴 직사각형**, 컷 사이 얇은 검은 테두리. 컷 좌상단에 원형 번호(❶~❽).
- **제목**: 각 컷 상단, 손글씨 느낌 한글 굵은 글씨.
- **말풍선**: 둥근 사각/타원, 손글씨 한글. 캐릭터 머리 위.
- **컬러 포인트**: 그래프/강조는 초록(상승)·빨강(하락). 로고색 등은 오버레이가 담당하니 그림엔 최소.

## ⭐ 오버레이 슬롯 규칙 (가장 중요)
- 아래 명시된 컷의 **지정 영역**은 **빈 상태**로 둔다 — 그 자리에 우리가 실데이터 애니 그래프/표/카운터를 얹는다.
- 슬롯 = **아주 연한 회색 테두리의 빈 사각형**(또는 그냥 여백). 안에 가짜 선·숫자·표를 그리지 말 것.
- **캐릭터·말풍선·제목은 슬롯을 절대 침범하지 않게** 반대쪽에 배치.
- 슬롯 위치는 "패널 내 비율"로 표기(좌상단 0,0 ~ 우하단 1,1).

## 컷별 상세

### ❶ 2021년, 시장은 정말 좋았다
- 표정: 밝음. 말풍선 "나스닥, 성장주 계속 오르네!"
- 캐릭터: 좌측, 폰을 보며 흐뭇.
- **오버레이 슬롯 A** (우측 중하단, 대략 x[0.45–0.95] y[0.45–0.85]): QQQ 2021 상승 그래프 자리 → **빈 박스**. (라벨 'QQQ' 정도만 옅게, 선은 그리지 말 것)

### ❷ 금리가 오른다는데 괜찮을까?
- 표정: 갸웃/고민. 말풍선 "금리 인상이라는데… 장기투자니까 괜찮겠지?"
- 우측에 회색 말풍선 3개(텍스트 그대로 그려도 됨): "인플레이션 급등" / "연준(Fed) 금리 인상 예고" / "시장은 불안…"
- 오버레이 슬롯: 없음(텍스트 컷).

### ❸ 결국 고민 끝에 선택했다
- 표정: 손 턱에 대고 고민. 말풍선 "지금 다 넣을까, 나눠서 넣을까?"
- 오버레이 슬롯: 없음(또는 아주 작게).

### ❹ 2022년 1월, 투자를 시작했다
- 표정: 결심. 캐릭터 하단 중앙.
- **두 방식 카드**(상단): 빨강 테두리 카드 "일시매수 / 모든 자금을 한 번에", 파랑 테두리 카드 "분할매수 / 6개월간 매달 동일 금액". → 카드 **틀·라벨만** 그리고 내부 금액/수치는 비워둠.
- **오버레이 슬롯 B** (두 카드 우측 여백 또는 카드 내부 하단, 각 카드마다): 금액 카운터(+투입액) 모션 자리.
- 하단 캡션 박스: "시작 시점: 2022년 1월"

### ❺ 그런데 바로 하락이 시작됐다
- 표정: 당황/식은땀. 말풍선 "왜 사자마자 떨어지지?"
- 캐릭터: 좌측.
- **오버레이 슬롯 C** (우측, 대략 x[0.4–0.95] y[0.4–0.9]): QQQ 2022 하락 그래프(−34.8%) 자리 → **빈 박스**. 하단 작은 빨강 캡션 자리 하나(비움).

### ❻ 버티는 과정에서 차이가 났다
- 표정: 두 캐릭터(또는 한 명 + 생각) — 일시매수쪽 "이미 전부 들어가서 할 수 있는 게 없어…", 분할매수쪽 "조금씩 사니까 평단이 낮아지고 있어."
- 상단 라벨 2개: 빨강 "일시매수" / 파랑 "분할매수".
- **오버레이 슬롯 D** (하단, 가로로 넓게 x[0.08–0.92] y[0.6–0.92]): 저점 최대낙폭 비교 박스 → **빈 박스**(두 칸 구분선만 옅게). 우리가 일시 −34.8% / 분할 −24.5% 애니로 채움.

### ❼ 시간이 지나 회복했다  ← **핵심 슬롯(가장 큼)**
- 표정: 담담/안도. 말풍선 "결국 둘 다 회복했지만 경로는 달랐네."
- 캐릭터: 좌상단 작게.
- **오버레이 슬롯 E** (컷 대부분, x[0.06–0.96] y[0.28–0.94]): **회복 그래프 + 24개월 결과 표** 자리 → **크게 비움**. 상단은 라인차트(2022-01→2024-03), 하단은 결과 표(최종자산·회복기간·손실기간·평균매입가 행 × 일시/분할 열). 표 틀도 그리지 말고 통째로 비워둘 것(우리가 그림).
- 하단 각주 자리: "※ QQQ 지수 기준" (옅게 두거나 비움).

### ❽ 결국 깨달았다
- 표정: 손가락 세워 교훈. 말풍선 "고점은 예측할 수 없지만, 한 번의 선택에 모든 걸 걸지 않을 수는 있다."
- 하단 노란 강조 박스(텍스트 그려도 됨): "일시매수는 시장에 오래 머무는 전략, 분할매수는 내가 틀릴 가능성까지 견디는 전략입니다." + 작은 별.
- 오버레이 슬롯: 없음(또는 작은 체크/별 모션).

### 하단 전체폭 캡션 바(선택)
"2022년 금리 인상기, 같은 시작이었지만 버티는 경험은 달랐다. 수익률뿐 아니라 '과정'도 투자에서 중요한 결과입니다."
(→ 우리가 8컷만 크롭해서 쓰므로 이 바는 있어도/없어도 됨)
