# 카툰 그리는 AI에 전달할 것 (핸드오프)

이미지 생성 AI에 **3가지**를 함께 준다:
1. **프레임 템플릿 이미지** (`_frame_template.png`) — "빈 자리(파란 점선) 위치" 시각 레퍼런스
2. **스타일 레퍼런스 이미지** — 기존 EP1~3 만화 1장(캐릭터 일관성 앵커). 없으면 텍스트 스펙만으로.
3. **아래 마스터 프롬프트** (컷별 내용만 채워서)

---

## 마스터 프롬프트 (복붙용 — [ ] 부분만 에피소드에 맞게 채움)

```
[스타일]
8컷(4열×2행) 한국어 투자 교육 만화. 순백 배경. 각 컷 세로 직사각형(약 1:1.9), 컷 사이 얇은 검은 테두리, 좌상단 원형 번호 ❶~❽.
캐릭터: 흑백 라인아트, 둥근 얼굴 + 삐죽삐죽 짧은 머리, 검은 반팔티 + 남색 반바지, 흰 신발. 심플·귀여움. 표정만 컷별로 변화. (첨부 레퍼런스와 동일 인물 유지)
제목: 각 컷 상단 손글씨 느낌 굵은 한글. 말풍선: 둥근, 손글씨 한글.
채색 최소(흑백선화 위주), 강조 컬러는 넣지 말 것.

[가장 중요 — 그래프 자리 규칙]
첨부한 프레임 템플릿(_frame_template.png)의 **파란 점선 위치**는 나중에 실데이터 그래프를 얹을 자리다.
· 그 자리는 **아무것도 없는 순백 빈 공간**으로 남긴다. 
· **박스 윤곽선·테두리·플레이스홀더·가짜 그래프·숫자·표·아이콘·라벨을 절대 그리지 말 것.** 그냥 빈 흰색.
· 캐릭터·말풍선·제목·표지판은 그 프레임을 **침범하지 말고 프레임 밖**(위/옆)에 배치.
· 차트 컷(⑥⑦⑧)은 캐릭터를 **작게 좌상단**에, 프레임 자리는 넓게 비운다.

[컷별 내용]  ← 에피소드마다 이 부분만 채움
❶ 제목 "[…]" / 말풍선 "[…]" / 표정 [기대] / 프레임 없음
❷ 제목 "[…]" / 말풍선 "[…]" / 표정 [놀람] / 우측 배지 프레임(빈 공간). 손에 "[표지판]" (옵션)
❸ 제목 "[…]" / 말풍선 "[…]" / 표정 [고민] / 프레임 없음
❹ 제목 "[…]" / 말풍선 "[…]" / 표정 [결심] / 하단 가로 프레임(빈 공간). 옆에 "[표지판]"
❺ 제목 "[…]" / 말풍선 "[…]" / 표정 [만족] / 우측 프레임(빈 공간)
❻ 제목 "[…]" / 말풍선 "[…]" / 표정 [의문] / 캐릭터 좌상단 작게, 하단에 큰 가로 프레임(빈 공간)
❼ 제목 "[…]" / 말풍선 "[…]" / 표정 [허탈] / 우측 큰 프레임(빈 공간)
❽ 제목 "[…]" / 말풍선 "[…]" / 표정 [깨달음] / 프레임(빈 공간) + 하단 노란 교훈 박스(텍스트 넣어도 됨)
하단 전체폭 캡션(옵션): "[…]"

[출력]
4×2 그리드 한 장. 위 프레임 자리는 반드시 빈 흰 공간.
```

---

## 체크리스트 (그림 받은 뒤 확인)
- [ ] 8컷 4×2, 세로 직사각형, 순백 배경, 번호 ❶~❽
- [ ] 캐릭터 = 기존 에피소드와 같은 인물(머리·옷·비율)
- [ ] **프레임 자리에 박스 윤곽선/가짜 그래프 없음 → 순백 빈 공간** (제일 중요)
- [ ] 캐릭터·말풍선이 프레임 자리를 안 가림
- [ ] 차트 컷(⑥⑦⑧)은 캐릭터 작게, 빈 자리 넓게

## 팁
- 표준 프레임 좌표는 `episodes/_frame_layout.json` 참고(에피소드마다 동일 재사용).
- "빈 흰 공간"을 AI가 자꾸 채우면(박스/그래프를 그리면) 프롬프트에 "leave blank white, no boxes, no charts, no placeholders in the marked areas" 강조·반복.
- 컷별 [ ] 채운 최종 프롬프트는 내가 에피소드 정해지면 만들어줄 수 있음(예: EP4).
