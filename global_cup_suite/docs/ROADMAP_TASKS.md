## ⚠️ 먼저 — 기획안 v0.1에서 수정된 중대 사실 5가지

1. **한국 사업자는 Stripe 계정을 열 수 없다.** Stripe 지원국 목록에 한국 없음(stripe.com/global).
   → "해외=Stripe, 국내=포트원" 지역 분기는 **한국 법인/개인사업자로는 Stripe 쪽이 불가**.
   대안: (a) **Merchant-of-Record**(Paddle·Lemon Squeezy)로 글로벌 판매 — 법인 불필요·부가세 대행,
   (b) 싱가포르/미국 법인(Stripe Atlas) 설립 후 Stripe. → **MoR가 솔로에게 현실적.** 🧑‍⚖️(세무)

2. **데이터 라이선스 비용이 기획안($20~80/월)보다 훨씬 크다.** 공급자들의 싼 개인요금제
   ($10~99)는 전부 **비상업(non-commercial) 라이선스 함정**. 상업+한국(KRX) 커버는
   **EODHD Enterprise €2,499/월**(재배포 허용) 또는 **Internal Use €399/월**(서버 내부용,
   파생 결과만 노출 시 — 🧑‍⚖️ 확인 필요). → **월 고정비를 $40~200이 아니라 최소 ~$450+로 재산정.**

3. **Streamlit엔 인바운드 HTTP 라우트가 없다.** 결제 Webhook을 받을 곳이 없으므로
   **별도 웹훅 서비스(FastAPI/Flask 또는 Supabase Edge Function)**가 반드시 필요.
   Streamlit은 구독 상태를 **읽기만**, 쓰기는 웹훅 서비스가 DB에 한다.

4. **Streamlit Community Cloud는 유료 상용에 부적합.** 12h 유휴 시 sleep, 커스텀 도메인 불가,
   리소스 캡. → **Docker 자가호스팅 + 스티키 세션**(세션 어피니티) 필수. 세션이 상태ful
   웹소켓이라 스티키 없이는 수평 확장이 깨진다.

5. **우리 도구는 자본시장법 리스크가 "낮음"에 가깝다 — 단, 설계 조건부.** 사용자가 종목을
   입력→과거 결과만 표시하는 순수 계산기는 안전권. **플랫폼이 종목을 추천/랭킹하거나,
   실시간 매매신호·1:1 상담을 넣는 순간 유사투자자문(신고)·투자자문(등록) 리스크로 격상**
   (2024.8 개정으로 형사처벌 강화). → §설계 규칙 준수 + 면책 문구 필수.

## Phase 0 · 유료화 MVP  `목표: 낯선 사용자가 가입→체험→결제→프로까지 막힘없이`

결제는 **MoR(Lemon Squeezy 또는 Paddle) 하나로 글로벌 시작** — 법인·사업자등록 없이
가장 빠르게 "지불 의사"를 검증한다. 국내 전용 PG(포트원)는 Phase 1에서 추가.

### 0-A. 인증 (st.login OIDC)
- [ ] IdP 선택(Google 우선 — 공식 튜토리얼 존재) 후 OIDC 앱 등록 → `client_id/secret/metadata_url` 확보.
- [ ] `.streamlit/secrets.toml`에 `[auth]` 블록(`redirect_uri`는 `/oauth2callback`로 끝나야 함, `cookie_secret` 랜덤). gitignore.
- [ ] `st.login()` / `st.user`로 로그인·사용자 식별. (Streamlit ≥1.42, OIDC 전용, 쿠키 30일 고정)
- [ ] 이메일/비번 가입이 필요하면 `streamlit-authenticator`(v0.4.x) 병행 검토.
- 사실: `st.login` v1.42.0(2025-02), `st.user` GA v1.45.0.

### 0-B. DB (Supabase)
- [ ] Supabase 프로젝트 생성. `supabase-py`(2.31.x) 또는 `st-supabase-connection` 연동.
- [ ] 스키마: `auth.users`는 건드리지 않음. `public.profiles`(FK→auth.users.id), `public.subscriptions`(plan, status, current_period_end, provider, customer_id, region).
- [ ] **모든 테이블 RLS 활성화** — SQL로 만든 테이블은 기본 OFF이므로 `enable row level security` 수동. 정책은 `auth.uid() = user_id`.
- 사실: Supabase Free(500MB·50k MAU, 1주 유휴 pause) / Pro $25/월.

### 0-C. 결제 (MoR — Lemon Squeezy/Paddle)
- [ ] MoR 선택(Lemon Squeezy: 개발자 친화·간단 / Paddle: 성숙). 상품(월/연) + 무료체험 설정.
- [ ] 체크아웃 링크로 유도(Streamlit은 서버 리다이렉트 불가 → `st.link_button`).
- [ ] MoR가 **부가세/판매세를 자동 처리**(솔로에게 큰 이점). 수수료 ~5% 감안.
- 🧑‍⚖️ MoR라도 국내 카드/카카오·네이버페이는 약함 → 국내 사용자 경험은 Phase 1의 포트원으로 보완.

### 0-D. 웹훅 서비스 (⚠️ 신규 컴포넌트)
- [ ] FastAPI/Flask 마이크로서비스(또는 Supabase Edge Function) 배포 — 결제 이벤트 수신 전용.
- [ ] 서명 검증(MoR/Stripe별 시그니처) → 2xx 즉시 응답, 이벤트 id로 멱등 처리.
- [ ] 처리 이벤트 → DB 반영:
  - 구독 생성/결제 완료 → subscription 행 생성, 접근권 부여
  - subscription updated(갱신·플랜변경·trialing→active·past_due) → 상태 동기화(**주 이벤트**)
  - subscription deleted/canceled → 즉시 접근권 회수
  - payment_failed → 알림, 즉시 회수 X(재시도/상태 이벤트가 결정)
- 원칙: **접근권의 신뢰원천은 웹훅이 쓴 DB이지, 체크아웃 성공 리다이렉트가 아니다.**

### 0-E. 엔티틀먼트 게이트
- [ ] 로그인 시 구독상태 1회 조회 → `st.cache_data(ttl=…)` + `st.session_state` 캐시. 유료 UI는 `st.fragment`로 감싸 매 클릭 재조회 방지.
- [ ] 프로 기능(다종목·FIRE 전체·내보내기·전 마켓) 게이팅. **session_state는 UX 캐시일 뿐, 실제 인가는 Supabase RLS로.**
- [ ] ⚠️ `st.cache_resource`·모듈 전역은 **프로세스 전역(모든 유저 공유)** — 테넌트 데이터 절대 넣지 말 것(누수 사고 1위).

### 0-F. 호스팅
- [ ] Docker 컨테이너화 → Cloud Run/Render/Fly.io. nginx/Caddy 웹소켓 업그레이드 + **스티키 세션** 설정.
- [ ] 시크릿(결제·DB 키) env/secrets로. 레포 커밋 금지.

### 0-G. 테스트 & 오픈
- [ ] MoR/Stripe 테스트 모드로 전체 라이프사이클(체험 종료·갱신·실패) 검증. Stripe면 **test clock** 사용.
- [ ] 기존 `AppTest` 헤드리스 테스트에 인증/게이트 경로 추가(유료화 회귀 방지).

## Phase 1 · 정식 런칭  `목표: 신뢰 가능한 유료 서비스`

### 1-A. 데이터 공급자 전환 (⚠️ 최우선·최대 비용)
- [ ] 상업 라이선스 계약 — 후보: **EODHD**(KOSPI/KOSDAQ 확인된 유일 후보), Tiingo/Polygon(미국·한국 없음).
  - Internal Use €399/월(서버 내부·파생결과 노출) vs Enterprise €2,499/월(재배포 허용). 🧑‍⚖️ "백테스트 결과 표시"가 재배포인지 서면 확인.
- [ ] 수집 레이어 재작성: 티커/거래소 접미사 규약 변경(예: 한국 `.KO/.KQ`).
- [ ] 배당/분할 조정 로직을 공급자 네이티브 adjusted-close·corporate-actions로 재작성(yfinance repair 워크어라운드 제거).
- [ ] **배당 정확도 교차검증**: 샘플 종목의 배당 총액을 2차 소스(IR 공시)와 대조 — FIRE/낙폭 숫자 신뢰성 확보.
- [ ] Rate limit/캐싱 재설계(일 10만 콜 캡 등). yfinance는 프로덕션에서 제거(로컬 dev 플래그만).
- 함정: 개인요금제=비상업 함정 / 한국 커버리지가 대부분 미국 벤더의 약점 / 파생결과 노출 라이선스 모호성.

### 1-B. 국내 결제 추가 (포트원 V2)
- [ ] **사업자등록**(최소 개인사업자) — PG 심사 전제. → **통신판매업 신고**.
- [ ] 서비스 배포 URL + 이용약관·개인정보처리방침·**정기결제 해지 절차 명시** 페이지.
- [ ] 포트원 가입 → PG 채널(토스페이먼츠 등) 신청 → PG 1차 심사(~3영업일) → **카드사 심사(~2주, 정기결제는 생략 불가)**.
- [ ] 빌링키 발급(`requestIssueBillingKey`) + 예약결제(`POST /payments/{id}/schedule`) 또는 자체 구독엔진(플랜변경·실패 재시도).
- [ ] 포트원 웹훅 → 0-D 웹훅 서비스에 통합(국내/글로벌 상태를 한 DB로).
- 사실: 포트원 기본 라우팅은 pass-through 무료(PG 수수료만). 카드 수수료 영세 0.4%~일반 ~3.4%. 정산 D+3~D+7.
- ⚠️ 규정: **무료→유료 전환·가격 인상 시 30일 전 사전동의** 플로우 필수. 🧑‍⚖️(세무: 해외 MoR 매출 vs 국내 매출 부가세)

### 1-C. 법률 · 규제 (🧑‍⚖️)
- [ ] 서비스 최종 스펙을 리스크표에 매핑(종목명 노출? 추천/랭킹? 알림/자동매매? 1:1 상담?).
- [ ] **안전 설계 규칙 적용**: 종목은 사용자가 선택(플랫폼이 추천 X) · "교육/시뮬레이션 도구" 반복 명시 · "매수/유망" 등 방향성 표현 배제 · 실시간 매매신호/자동매매/랭킹 리스트 미탑재 · 고객센터는 기술지원 한정(종목 Q&A 금지).
- [ ] **면책 문구**(아래 부록)를 가입 동의·결과 화면 하단·약관에 반복 배치.
- [ ] 경계선("중간" 이상)이면 금융위 **금융규제민원**(better.fsc.go.kr) 질의 또는 변호사 검토 → 필요 시 유사투자자문업 신고.
- [ ] 광고 문구 전수 검토(수익보장·수익률 과장·금융사 오인 표현 제거).

### 1-D. 런칭 준비
- [ ] 랜딩페이지 + 콘텐츠(유튜브) → 앱 유입 링크. 가격/티어 확정(A/B).
- [ ] 결제·환불·해지 정책, 소비자보호 규정 반영.

## Phase 3 · 앱 (조건부)  `수요 확인 시에만`

### 3-A. 구글 플레이 (빠른 길)
- [ ] PWA를 **TWA**(Trusted Web Activity)로 래핑 — Bubblewrap/PWABuilder. Digital Asset Links 도메인 검증.
- [ ] 결제: 구글 플레이 신모델(구독 서비스요금 ~10% + Play Billing 사용 시 +5%). 한국/미국/EU 대체결제 가능(대체결제도 ~26% 한국).
- 판정: **구글 플레이는 TWA로 통과 가능**(상대적으로 관대).

### 3-B. iOS (어려운 길)
- [ ] ⚠️ **Streamlit URL 단순 웹뷰 래핑은 Apple 심사 리젝**(Guideline 4.2.7(e) "클라우드 앱의 thin client"). PWA도 iOS는 미제출.
- [ ] 통과하려면 **네이티브 가치** 필요: 네이티브 UI/내비, APNs 푸시, 오프라인, 기기기능 — 사실상 **프론트 재작성(React Native/Flutter) + 파이썬 엔진 FastAPI 백엔드화**.
- [ ] 결제: 미국은 외부결제 링크 허용(현재 수수료 0%지만 **잠정** — 9순회 항소심이 뒤집어 대법원 계류, 비용 부활 대비). EU DMA 외부링크(잔여수수료). 한국 대체결제 ~26%.
- [ ] "무료 앱 + 웹에서만 구독" 패턴: 기존 Reader 예외는 SaaS에 **미적용**. 대신 **미국 신 스티어링 규칙**(2025-05, 모든 미국 앱 외부결제 링크 허용)에 기댐.
- 판정: iOS는 **네이티브 재작성이 정답**. 급하면 구글 플레이만 먼저.

## 부록 · 면책 문구 (한국어 초안, 🧑‍⚖️ 최종 검토 필요)

> 본 서비스는 사용자가 설정한 조건에 따른 과거 데이터 기반 시뮬레이션(백테스트) 결과를 제공하는
> **교육 및 정보 제공 목적의 도구**이며, 금융위원회에 등록된 투자자문업자 또는 신고된
> 유사투자자문업자가 아닙니다. 제공되는 모든 결과는 **특정 금융투자상품의 매수·매도·보유를
> 권유하거나 추천하는 것이 아니며**, 투자자문 또는 투자권유로 해석되어서는 안 됩니다.
> **과거의 백테스트 성과는 미래 수익을 보장하지 않으며**(거래비용·세금·슬리피지·유동성 미반영 가능),
